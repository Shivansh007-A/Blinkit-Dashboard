## Overview

Developed an interactive Blinkit Sales Dashboard in Power BI to analyze sales performance, outlet efficiency, customer ratings, and product distribution. The dashboard provides business insights through dynamic KPIs, interactive filters, and visual reports, enabling data-driven decision-making.

## Features
  Interactive filters for Outlet Location Type, Item Type, and Outlet Type
  KPI cards displaying Total Sales, Average Sales, Number of Items, and Average Rating
  Sales analysis by Item Type
  Fat content distribution across products
  Outlet location-wise sales analysis
  Outlet size-wise sales comparison
  Sales trend by outlet establishment year
  Outlet type performance comparison
  Interactive charts, KPI cards, tables, and slicers

## Tools & Technologies

## Key Insights
  Identified top-performing outlet types and locations by sales.
  Compared sales across outlet sizes and establishment years.
  Analyzed customer ratings and average sales performance.
  Evaluated product distribution by item type and fat content.
  Enabled dynamic filtering for detailed and interactive business analysis.
